## What I learned

The open-source contribution loop, which I'll reuse for every future contribution:

1. **Fork**: make my own copy of someone else's project
2. **Branch**: start a separate line of work for my change
3. **Commit**: save the change with a clear message
4. **Push**: upload the branch to my fork
5. **Pull request**: ask the project's maintainers to merge my change
